# configurationrealism.com

Static site (GitHub Pages) for Configuration Realism: papers, toy-model code, and results.

## Structure

```
.
├── index.html            # site
├── CNAME                 # custom-domain file (do not delete)
├── papers/
│   ├── born-exponent.pdf / .tex       # The Born Exponent from Counting (v5)
│   ├── chsh-by-counting.pdf / .tex    # CHSH by Counting (v2)
│   ├── foundations.pdf / .tex         # Configuration Realism: Foundations and Research Program (v5)
│   └── archive/                       # superseded versions, kept for the record
├── code/
│   ├── cr_toy_model.py                # Born by counting: 6 test suites
│   ├── step1_multiplicativity.py      # product consistency vs conservation; eraser
│   ├── step4_stability.py             # einselection, redundancy, V^2+D^2=1
│   ├── chsh_by_counting.py            # CHSH at 2*sqrt(2) by counting
│   └── chsh_figure.py                 # generates figures/chsh_results.png
└── figures/
    ├── toy_model_results.png          # generated by cr_toy_model.py
    ├── step1_results.png              # generated by step1_multiplicativity.py
    ├── step4_results.png              # generated by step4_stability.py
    └── chsh_results.png               # generated by chsh_figure.py
```

Filenames are stable (no version numbers) so links never rot; the version lives on
each paper's title page, and superseded PDFs move to `papers/archive/` (e.g.
`born-exponent-v4.pdf`) when replaced.

## Running the models

```
pip install numpy matplotlib
python3 code/cr_toy_model.py
python3 code/step1_multiplicativity.py
python3 code/step4_stability.py
python3 code/chsh_by_counting.py
```

Each script prints its tests and verdicts and regenerates its figure. The figure
paths inside the scripts assume they are run from the `code/` directory (or adjust
the output path); commit regenerated figures to `figures/`.

## Rebuilding the papers

```
cd papers && pdflatex born-exponent.tex   # twice, for cross-references
```

The papers' figure includes expect the PNGs alongside the .tex file; copy from
`figures/` before compiling, or symlink.
