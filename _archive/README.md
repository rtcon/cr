# _archive — Provenance Record

Version-controlled history of the framework's development. This folder is
**not deployed** to the website (excluded via `_config.yml` and Jekyll's
underscore convention) but is **fully visible in the public repository** —
commit only material suitable for public view. For unredacted originals,
retain the original privately and commit its SHA-256 hash below: that
establishes proof of existence by commit date without disclosure.

The deployed `papers/archive/` folder serves a different purpose (superseded
paper versions, kept at stable public URLs); development history belongs here.
